# Daily Bugle

### Your Daily Dose of New York News!

Daily Bugle is a Spider-Man-inspired news website created as a frontend development project. It features fictional news stories, a newspaper-style layout, and a simple user-friendly interface.

## Features

* Homepage with featured news stories.
* Multiple news story cards.
* Search functionality.
* Category-based news filtering.
* Individual article pages.
* Save articles for later.
* Responsive design for different screen sizes.

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Vite

## 💻 How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install dependencies:
   npm install
5. Start the development server:
   npm run dev
6. Open the local URL shown in your terminal.

## 🎯 Project Purpose

This project was created to practise frontend development, React.js, CSS styling, and building an interactive website.
